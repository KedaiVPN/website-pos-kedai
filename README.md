# website-pos-kedai

Landing page resmi POS Kedai — Solusi Aplikasi Kasir Digital UMKM & Toko Retail.

## Fitur
- Landing page informatif, modern, dan responsif untuk aplikasi POS Kedai
- API endpoint untuk pengumpulan data prospek / lead demo (`/api/lead`)
- Aset lengkap dan siap integrasi

## Instalasi & Menjalankan

```bash
# Install dependensi
npm install

# Jalankan server
npm start

# Mode development (auto-reload)
npm run dev
```

Server berjalan di `http://localhost:3001` secara default (port dapat diubah via environment variable `PORT`).
